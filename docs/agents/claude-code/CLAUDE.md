# Claude Code — per-project override notes

This file is **not** a duplicate of the root `CLAUDE.md`. Claude Code auto-loads the root
file; this one exists only for notes that are specific to *this* copy of the skeleton and
would be noise in the root file (e.g. a temporary local workaround, a note about a
in-progress migration off a legacy system, a reminder about a quirk in this environment).

If you find yourself copying whole sections of the root `CLAUDE.md` in here, stop — that's
the duplication pattern that caused the root/`docs/instructions/` `CLAUDE.md` files in
one of the reference projects this skeleton was extracted from to silently drift out of
sync with each other. Add a link back to the root file's section instead of restating it.
