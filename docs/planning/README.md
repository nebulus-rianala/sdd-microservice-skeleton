# Planning

Planning documents translate the technical spec into a **sequenced delivery backlog** —
weekly (or otherwise time-boxed) batches of work, each with concrete deliverables and the
prompts needed to generate and validate them.

Planning documents are **not** specifications. They reference the spec but do not replace
it. **If a planning document contradicts the spec, the spec wins** — fix the plan, don't
let the plan quietly redefine what's being built.

This folder is generator 2's output — see `docs/skills/generate-planning.md` /
`docs/prompts/02-generate-planning.md`. It starts empty; the plan file
(`{{SERVICE_NAME}}-plan.md`) is created the first time generator 2 runs.
