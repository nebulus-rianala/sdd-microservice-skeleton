# Known assumptions from the skeleton's own bootstrap

This skeleton was generated by extracting conventions from two real Key Predict services
(a mature Laravel reference and an earlier-stage FastAPI reference), not invented from
scratch. Most of it traces directly to one or both references. The items below are the
exceptions — places where no reference actually covered the topic, or where a real
decision (not an extraction) had to be made. Read this once before your first clone; it
explains a few things in `CLAUDE.md`, the stack profiles, and the ADRs that might
otherwise look unmotivated.

- **`memory/` folder (lessons-learned cache).** The Laravel reference has one (a
  debugging-notes cache distinct from ADRs/audit records); the FastAPI reference doesn't;
  the bootstrap prompt's required tree doesn't call for one. Left out of this skeleton as
  out of scope, not silently added. Add a 4th folder alongside `docs/adr/`, `docs/audit/`,
  `docs/context/` if your team wants it.

- **FastAPI-side conventions borrowed from the Laravel reference.** The FastAPI reference
  was functionally less mature at bootstrap time (its own plan was still in Phase 0/1, no
  completed weekly cycle, no fix-story convention). Its planning format, security-folder
  shape, audit-record shape, and runbook shape don't exist yet in that project — this
  skeleton carries the Laravel reference's versions of those over to both stack profiles
  rather than inventing a third format. Unvalidated against a second real FastAPI project.

- **CI templates are not included.** Neither reference's CI config is in the skeleton's
  required output tree. Worth knowing: the FastAPI reference's own CI reports coverage but
  doesn't gate on the `--cov-fail-under` flag the way its local dev command does — don't
  silently reproduce that gap if you add CI templates later.

- **`{{ID_PREFIX}}` is a real decision, not an extraction.** The FastAPI reference never
  used a letter prefix for story IDs (`001-slug.md`, not `KX-001-slug.md`). Standardizing
  both stacks on `{{ID_PREFIX}}-###` was a deliberate choice to unify the two conventions.

- **MySQL guidance is unsourced.** Both references only ever run against PostgreSQL
  (`DATETIME`/database-agnostic framing in Laravel, SQLAlchemy + `JSONB` in FastAPI). The
  MySQL-alternative guidance in the stack profiles comes from this ecosystem's stated
  default/alternative split, not from either reference actually running on MySQL — treat
  it as unvalidated until a real MySQL-backed service exercises it.

- **Kong consumer-group values are placeholders, not fixed constants.** The Laravel
  reference's actual values (`evaluator`, `admin`) are project-specific. Only the header
  *names* (`X-Consumer-Groups`, `X-Consumer-Id`) and the trust mechanism are fixed
  ecosystem facts; the group values themselves are filled in by generator 1's interview
  per service.
